# Changelog

## Streamlit v0.2.0 — local beta candidate

- added scientific introduction and versioned methodology documentation;
- added disease-specific annual and cumulative trends;
- added reported study-context geography with explicit limitations;
- enabled per-record community audit links;
- added controlled audit and missing-article forms;
- added local audit outbox and optional Formspree delivery;
- added snapshot downloads and provisional citation guidance;
- preserved the immutable v0.1 pilot snapshot and scientific denominator rules.

### Local visual-polish revision — 2026-08-31

- added responsive cards, typography and mobile sidebar behavior;
- reduced visual density in Article Explorer and Methods & Data Quality;
- made semantic coverage visible for both all-disease and disease-filtered views;
- shortened analytical metric labels while preserving detailed definitions in help text;
- clarified the study-context geography boundary and documented future
  author-affiliation country and responsible-institution dimensions separately;
- completed desktop and narrow-viewport browser QA across the public interface;
- increased the automated suite to 69 passing tests.

### Public beta packaging revision — 2026-09-09

- paired Streamlit v0.2.0 with the accepted Power BI v0.2.1 canonical desktop
  and mobile layout;
- added an allowlist-based public release builder that refuses overwrite;
- added privacy, credential and personal-path scans to release packaging;
- added a deployment, post-deployment acceptance and rollback protocol;
- preserved the immutable public snapshot and kept community auditing exclusive
  to Streamlit.
