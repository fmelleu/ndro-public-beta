# Citation and reuse

## Provisional dataset citation

Until a DOI and complete contributor list are assigned, cite the exact snapshot
used rather than citing an undated live interface:

> NDRO Project. *Neurodegenerative Disease Research Observatory public
> snapshot*. Version **{snapshot_version}**, cutoff **{cutoff_date}**. Public
> snapshot contract **{contract_version}**.

Include the access date and public application URL after deployment.

## Reproducible reuse

Record the snapshot version, cutoff date and checksum file with every analysis.
Do not combine association counts with unique-publication counts without
explicitly stating the denominator. Preserve PubMed source attribution when
redistributing source-derived fields.
