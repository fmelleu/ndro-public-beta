## Data

- `snapshots/synthetic-ui-fixture-v0.1/` is a **synthetic fixture**
  provided in the authoritative input package
  (`sample_snapshot/*`), copied here unmodified. It exists only to test
  this interface and does not represent real NDRO or PubMed records. Its
  own `snapshot_metadata.json` states `"synthetic_fixture": true` and
  `"source": "Synthetic UI fixture; never present these records as real
  NDRO or PubMed data"`.
- `contracts/NDRO_Public_Snapshot_Data_Contract_v0.1.md` is copied from the
  authoritative input package unmodified, for in-repo reference.
- No PubMed content was fetched, scraped, or generated by this
  application. PubMed URLs shown in the UI (`pubmed_url` field) are taken
  directly from the snapshot's own data and are standard public PubMed
  article links (`https://pubmed.ncbi.nlm.nih.gov/<pmid>/`); this app does
  not call PubMed's API or verify link reachability.
- NDRO-authored structured annotations are offered under CC BY 4.0 only to the
  extent described in `DATA_LICENSE.md`. PubMed- and publisher-derived titles,
  abstracts, bibliographic metadata and verbatim evidence are not relicensed by
  NDRO.

## Fonts, icons, and images

No external font files, icon packs, or images are bundled or fetched by
this app. The only visual elements beyond text are:

- A single emoji (`🧠`) used as the browser tab icon (`page_icon` in
  `app.py`).
- Small inline HTML/CSS "badges" (colored rounded labels) generated
  entirely from CSS in `ndro_app/cards.py` — no image assets.
- Altair-rendered charts (SVG, generated at runtime from snapshot data).

## Community-audit control

Each article card links to a prefilled report form under **Audit &
Corrections**. A valid local-development submission is appended to
`local_audit_outbox/submissions.jsonl`, which is excluded by `.gitignore`.
In production, delivery is enabled only when a valid Formspree endpoint is
provided through Streamlit secrets. The endpoint and reporter data are not
stored in source control, and submissions never alter the public snapshot or
canonical classifications automatically. See `docs/AUDIT_POLICY.md` and the
README configuration instructions.
